# GeneWeaver

GPU-Accelerated CRISPR Alignment Engine

GeneWeaver is a high-performance bioinformatics project designed to detect potential CRISPR off-target mutations using GPU-accelerated DNA sequence alignment.

## Technology Stack
- Python
- BioPython
- Numba CUDA
- Dask
- Textual

## Project Domain
Bioinformatics & High-Performance Computing (HPC)
